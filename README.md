## Install

Copy the pet folders into the pets directory on your computer:

- Mac or Linux: `~/.codex/pets/`
- Windows: `%USERPROFILE%\.codex\pets\`

Each folder has to stay named `jawa-bot`, `trooper`, or `at-at`. Then open ChatGPT or Codex, go to **Settings → Pets**, and choose **Refresh**.

You can also upload a single `spritesheet.webp` from **Settings → Pets → Upload pet**. The upload uses the picture only. Copying the folder keeps the pet name and the BRS Store credit.
